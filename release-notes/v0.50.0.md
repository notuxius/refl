- Relf verifies the download before asking a running app to close. **Waiting for the app to close** gives you time to save or discard changes. Relf applies the update and relaunches the app after installation succeeds. For apps with a separate installer, set **Running app EXE (optional)** in **General**. Other file locks show **Files in use**.
- **Install** can copy portable ZIP, 7z, and RAR packages or local app folders into your Windows Programs folder and add a Start menu shortcut. Choose the launcher when the package contains several executables. Updates preserve portable settings and files you added.
- **Options → App folder** lets you publish apps to a separate library. Restart Relf after choosing it. To map a specific item to its own folder while keeping the publisher's filename, use a target ending in `{filename}`.
- After a successful update, Relf removes the current download from the cache and keeps up to one previous version by default. Change the limit in **Options → Previous versions to keep per app**. Offline verification still checks the published files. Repairs may need to download the package again.
- Relf skips updates that would replace a newer Windows executable with an older one. Full-folder packages can also run packaged setup commands such as `Install.cmd`.
- Options scrolls on shorter displays and keeps **Close** visible.
