- **ReleaseShelf is now Relf.** The Windows download is named `Relf.exe`. Put it next to your existing `recipes` folder to keep using your app list, and update any pinned shortcuts to the new executable. The older Python launchers still work.
- **Choose a download folder in Options.** Open **Download folder → Browse…** and restart Relf to apply the change. The CLI uses the same setting, with `--dest` available as an override. Fresh installs default to `Downloads\Relf`. Upgrades automatically reuse an existing `Downloads\PortableFetch` or `Downloads\ReleaseShelf` folder unless you choose a different location.
- **Resize app list columns.** Drag a divider to set a width, or double-click it to fit the heading and the items on the current page. Relf remembers widths across restarts and saves separate layouts for Tracked and Checklist.
- Relf redraws the window before showing it again after minimizing, reducing flicker on Windows.
