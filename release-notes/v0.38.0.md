- Relf opens faster, and the app list stays responsive while it loads icons from EXEs, MSI installers, and ZIP archives. Saving an item refreshes the rows that changed.
- Ready downloads can start while other publishers are still being checked. The status row adds the total once the checks finish, and the final summary shows updates, cached repairs, up-to-date items, pending publications, errors, and cancellations.
- Downloads and repairs read large files fewer times while still verifying SHA-256 before publishing. **Verify files** still performs a full offline check.
- Windows 11 ISO recipes can use an optional mirror when its checksum matches the one Microsoft publishes. If the mirror is unavailable or Microsoft lists a different checksum, Relf uses the Microsoft download link.
