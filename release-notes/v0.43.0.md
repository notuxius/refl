- Relf checks for its own updates when it opens. Click **Relf update available** in the bottom status row to read the release notes, or use **More → Check for Relf updates**.
- **Update and restart** verifies the download, replaces the executable in place, and reopens Relf with your app list and settings. Relf restores the previous executable if the updated window fails to open.
- To start using the updater, close Relf and replace `Relf.exe` with this release once.
