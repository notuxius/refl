- Relf checks for its own updates at startup and every 24 hours while it stays open. When it finds a new version, it downloads and verifies the executable in the background.
- **Relf update available** appears when the update is ready. Clicking it installs the update and restarts Relf immediately, even if you’re offline or GitHub is rate-limiting update checks.
- Use **More → Check for Relf updates** to check immediately and review the release notes before installing.
