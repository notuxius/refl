- The app list now shows **Close and Install** for a running app. Relf waits for it to exit before installing. If the installer and app use separate executables, set **Running app EXE** under **Edit item → General**.
- Updates blocked by an open app show **Waiting for the app to close**. Relf keeps the verified download and applies it automatically after the app exits, even if you reopen Relf in the meantime.
- Relf skips downgrades when it can compare the installed and offered versions. This applies to cached repairs and queued updates as well as downloads.
- Batch updates adjust concurrency to publisher responses and retry temporary failures. When GitHub rate-limits requests, Relf waits for the reset while it continues checking other publishers.
- ISO target filenames can include `{version}`. After a successful update, Relf removes the previous ISO only if its checksum still matches the saved copy.
- Direct-download installers can still report a version when the server ignores range requests. Relf reads one complete response for installers up to 32 MiB.
